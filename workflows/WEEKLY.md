# 每周执行流程

## 一、周度输入

1. 本周全部标准快照、Judge review、Trader order intents、Broker fills 和分层 Score。
2. Tushare 的本周末日线、周度涨跌、成交额、市场 breadth、涨停生态和代表股票数据。
3. 活跃父题材/分支的完整 episode 时间线。
4. 用户周度补充和老骚视频会议原文。
5. 资料时间、来源和可知时点必须完整。

## 二、先把当周行情看明白

- 市场：指数、量额、风格、赚钱效应和容错如何变化。
- 板块：主线、伴生、低位分支、缩容、抱团和切换。
- 个股：核心、前排、后排怎样分化，哪些走势具有主动性。
- 策略：A/B、核心/弹性、成交/未成交、成本后 R 和尾部风险。

文字复盘必须和上述数据及代表图形对照，避免只凭叙事理解一周。

## 三、老骚会议对照法

### 1. 原文拆分

每段内容标成：

- 对本周已经走完后回顾；
- 对当前市场状态的描述；
- 对下周或更未来的前瞻判断；
- 具体题材/股票机会；
- 交易方法与纪律。

记录原话、会议时间和涉及标的，不改写成我自己的观点。

### 2. 与当周行情核对

- 哪些描述有行情数据支持；
- 哪些与核心/后排、 breadth 或成交结构不一致；
- 哪些是事后解释，哪些在当时具有可交易信息；
- 我同意、不同意或证据不足，分别写理由。

### 3. 前瞻观点延迟验证

会议中的下周机会先锁成观察卡，不在本周复盘里用下周结果评分。下周结束后才记录触发、路径和结果。

### 4. 案例化

只有具备时间、市场背景、判断、反证和后续验证的内容才进入 `cases/external/laosao/`。专家身份本身不是证据。

## 四、周复盘产出

1. 本周市场地图及状态迁移。
2. 策略分账和执行偏差。
3. 1—3 个成功/失败/错过案例。
4. 老骚观点对照表及待验证机会。
5. 1—3 条可证伪 insight：观察→假说→证据→反例→适用环境→失效条件。
6. 下周明确预判和观察条件。
7. 需要进入 `framework/research/` 的候选改动。

周复盘不直接修改 `framework/current/`。

## 五、每月最后一周追加

- 市场状态是否迁移，首分 edge 是否漂移。
- 旧框架在哪些环境仍有效、哪些环境失效。
- 挑战者与冻结基线的样本外对比。
- 是否允许规则晋升、继续观察或回滚。

## 六、落档

```text
reviews/weekly/YYYY-Www/
  market.md
  strategy.md
  laosao-review.md
  insights.md
  next-week-watch.md
cases/external/laosao/
```

每周只增加证据，不追求每周都必须产生规则改动。

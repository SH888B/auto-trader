# F016 切换日判定标准

- **分类**：时点信号
- **applies_to**：judge, trader
- **陈述**：切换日 = 上一主流板块结束、下一方向启动的衔接日。判定锚定板块整体而非核心票：**中后排集体负反馈先于核心票**（核心票因资金惯性可再抗跌两三天）；核心票**结束K = 连续两根跌停**，温和阴跌（每日 -2/-3%）≠ 结束（金健米业 9/8-9/11 三根温和阴跌、9/15-9/16 二连跌停才算结束）；切换确认至少看两个交易日；提前启动的方向必须在切换日扛住分歧，两天都扛住 = 分离确认
- **出处**：老骚 JDFS 复盘多案例（0614 框架课、0927 结束K形态学、1007 分离确认流程、1018 切换日质量评估）
- **判别数据**：板块内涨跌幅分布（中后排负反馈）、核心票日K、跌停结构、候选方向启动首板
- **验证指标**：切换日判定后 T+1/T+2 候选方向平均涨幅；误判率（把温和阴跌判为结束）
- **状态**：已入框架（外部多案例一致；本系统内待首个实验验证）

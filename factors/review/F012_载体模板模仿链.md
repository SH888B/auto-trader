# F012 载体模板模仿链

- **分类**：观察项（暂定，验证后可升时点信号）
- **陈述**：**模仿不限于连板空间板，对所有载体类型成立**（连板龙头/核心票/20cm 中军皆有模板传递）；**模板的本质是多浪"剧本"而非单段形态**——典型剧本：一波连板 → 高位平台横盘 N 日 → 二波 → 高位滞涨/退潮。模仿沿两个方向发生：①新票照剧本启动（赛福天抄大业加速段）；②更关键的——**持仓资金在遇到剧本写过的剧情节点（断板）时，因模板源的成功先例而敢于按剧本操作**（大业断板后资金敢接，因为九阳剧本写着"断板后横几天有二波"）。同一条模仿链上剧本逐代压缩（九阳平台期 3 日 → 大业 2 日；大业 6 连板到分歧 → 赛福天 4 板即软开板），**连续两代压缩=该载体类型降档信号**。**剧本失效模式：二波不能如期确认 → 按剧本接的资金怀疑 → 模板置信度崩塌 → 同链模仿者被同时抛弃（链式瓦解，非逐个倒）**
- **出处**：用户 2026-10-27 晚提示（"赛福天模仿大业、大业模仿九阳、深赛格模仿大业/赛福天"；并指出"模仿不仅仅是连板龙头，对核心、20cm 也是如此，这是很抽象的概念"）
- **证据**（n=1 条完整链 + 若干单侧，样本极小，第一阶段以结构化记录为主）：
  - 九阳剧本全貌（用户 10-27 晚供图核实）：9/28 启动 → 一波连板至 10-14（17.69）→ 高位平台横盘 3 日（10-14~16）→ 二波 3 日至 22.62（10-21）→ 高位滞涨出货（10-22 至今，区间 +127%、换手 221%、主力净流出）
  - 10cm 连板链：九阳（"连板-平台-二波"剧本模板源）→ 大业 10-23 断板复刻其一波结束位 → 平台压缩为 2 日（10-24/25）→ 10-26 +8.08% 二波尝试（成色待确认）→ 赛福天 1/1→4/4 复制加速段、第 4 板即软开板（成交 3.02 亿=前日 5 倍，尾盘封单 0.25 亿=昨日 1/12）→ 深赛格 1/1 首板一字复制启动
  - 20cm 链：善水科技首开 20cm 三连天花板 → 华阳智能 20cm 三连（直抄）→ 凡拓数创"20cm 趋势中军"变体（不抄连板、抄强趋势形态）
  - 节奏压缩数据点：平台期 3 日→2 日；到分歧点板数 6→4
- **工程落点**：
  1. 模板编码：按载体类型分别建**剧本剧幕**序列（启动→一波加速→高位平台→二波→滞涨/退潮；连板票看封板方式/一字天数/封单环比/断板量能，20cm/核心票看涨幅节奏/量能平台/回撤深度），软开板进编码（F008 演进条款）；每只活跃载体标注当前剧幕 + 已在该剧幕停留天数（对照模板源同期读数）。**已实现（lc0.2，selectors s0.5）**：`derived/carrier_lifecycle.csv` 22 行 + digest 第四层渲染；单波边界=收盘破 5 日线（用户拍板 2026-10-28），破线只认本波启动日（窗口内首个涨停日）之后；20261027 回放验收 7/7 命中。剧幕级联优先级：退潮·破5日线→退潮(辅助)→二波·新高/重启(须 prior_break)→一波加速→单波·二波尝试→高位平台→滞涨→主升分歧→观察/观察·线下
  2. watchlist 字段：`template_of`（模仿自）/`template_stage`（模板阶段）/`template_ttl`（模板源当年该阶段剩余时间）
  3. digest：载体生命周期分组 + 天花板两行（见 F013，共用管道）
- **验证指标**：
  - V1：衰减信号后 2 日内同类型载体批量证伪命中率
  - V2：模板源破位次日，模仿者收跌的条件概率 vs 基线
  - V3：模仿关系判定的事后人工复核一致率
- **样本计划**：先结构化记录 20-30 个载体（每日判定读数落盘），再谈回测；记录层归 E004 实盘延续期（每日 carrier_lifecycle.csv + watchlist 模仿标注）；独立验证实验建议编号 E006（待 E005 收口后立项）
- **数据缺口**：收盘时点封单（当前 fd_amount 为首次封板时点值）
- **状态**：假设

# Judge 执行模板 v2（对应复盘框架 v1.0 / selectors s0.3 / digest v3）

> 本文件是 Judge 的**唯一执行规范**。v1 归档于 judge_prompt-v1.md（E001/E002 回放使用）。
> 变更原因（E003）：复盘体系从三层升级为四层（市场环境→市场结构→板块行进→载体），digest v3 新增坑货榜/周涨幅/20cm中军/三分法/连板梯队视图。

## 铁律

1. **回放纪律**：第 T 天的判断只允许读 T 及之前日期的快照；严禁读任何 T 之后的 digest / derived / curated。违反则本次实验作废。
2. 四层结构必须自上而下：第 1 层（市场环境）不合格时，下层结论再好也不得给 buy（容错率优先）。
3. 每个判断必须引用 digest 中的具体数据（数字、票名）； checklist 每项标注 ✅/❌/缺数据，缺项进数据缺口。
4. 输出落盘前必须通过 `scripts/judge/validate_plan.py` 校验，不合格返工。

## 输入（按顺序读）

1. 我知道：`framework/current/每日复盘体系_v1.md` + `context/factors/registry.yaml`（状态=已入框架的因子必须遵守）
2. 我看到：`data/snapshots/<T>/digest.md` + `derived/`（limit_up 明细、坑货榜、周涨幅、20cm中军）
3. 我持仓：`data/positions/current.yaml`
4. 我的关注列表：`data/watchlist.yaml`（唯一事实源；每日复盘必须显式维护：确认 anchor、升/降级 level、移出留痕）

## 输出 1：review.md（四层复盘 + 错题本）

```markdown
# 复盘 <T>
## 1. 市场环境（钱在入市还是流走？）
指数面板解读：全A形态 → 结构对比（双创 vs 银行 vs 中证2000 = 风偏方向）→ 量能/广度 → 容错率结论。
## 2. 市场结构（什么方向/风格好？）
三分法板块各自的状态：投机板块（轮动节奏）/ 成长板块 / 避险板块；哑铃两端谁走强。
## 3. 板块行进（流动性周期位置）
活跃板块逐个：主升/切换/补涨/抱团/退潮 定位 + 证据（涨停家数/梯队/坑货榜/周涨幅）；
首板启动方向有没有新题材萌芽；坑货榜反映的板块分歧点。
## 4. 载体（个股）
watchlist 逐个过：anchor 今日表现与明日预案；空间板梯队（只观察）；20cm 中军（F007 低吸优先象限）；
成交额榜里的机构趋势票与板块中军；空间感（高位票本波涨幅记录）。
## 5. 错题本
对照 <T-1> 的 plan.json 逐条验证；错因归类（周期/题材/个股/执行纪律）；是否触发框架因子（引用 F 编号）。
## 6. watchlist 维护记录
新增/移出/改级别，每条给 reason（这是强制段，不许省略）。
```

## 输出 2：plan.json（次日交易计划）

结构与 v1 相同（date/confidence/market_view/actions/kill_switch），补充规则：

- thesis_tag 取值扩展：`主线接力 | 空间板 | 低吸 | 20cm中军 | 抱团观察 | 防守 | 其他`（20cm中军=F007 专用标签）
- buy 限制（F003/F010）：高潮次日、分歧预期日，禁止 2 板以上接力；低吸优先挂 20cm 中军与前排换手票
- 每个 buy 的 reason 必须说明：属于哪个板块（引用三分法类型）、周期位置依据、以及"什么情况证明我错了"（反证）
- kill_switch 遵循 F004 双条件制
- watchlist 中的 anchor 断板/反包必须出现在 market_view 或 kill_switch 中
